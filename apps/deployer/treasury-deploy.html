VELTRON Treasury Deployment

Dedicated Testnet-only deployment for veltron-treasury.testnet. Deployment and initialization are separate. This page can request exactly one DeployContract action; it cannot initialize or transfer tokens.

Testnet only. No mainnet deployment.

Never enter or upload a seed phrase, private key, or wallet backup. Verify the transaction details in Meteor before approving.

4. Request one deployment action

Wallet approval is the only point at which a transaction can be sent. Check that Meteor shows Testnet, signer and receiver both veltron-treasury.testnet, exactly one DeployContract action, and no initialization or token transfer. Reject anything different.

Locked until the file, account, network, and fresh preflight checks pass.

After deployment

The page will read finalized on-chain contract code and compare its SHA-256 to the CI artifact. A successful match proves code identity only. Stop there: initialization remains a separate step requiring its own review and approval.
