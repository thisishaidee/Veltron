What happens after deployment?

Only the contract code changes. NEAR's DeployContract action does not run an initializer. Existing state must be re-read and validated after the upgrade. We will separately verify the new code hash, initialized state, reserve, commitments, pause status, pending transfers, token audit, account balance, and storage.

No initialization or token movement is available on this page. The existing treasury state must not be reset.

A CI pass and a matching local file do not prove a live wallet approval. The wallet prompt is the final authority for what you sign. No transaction is sent until you explicitly press the review button and approve in Meteor.
